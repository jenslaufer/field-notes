# Width buys averaging, memory buys structure, delay buys nothing back

## Read the domain line before the result line

**This paper contains no LLM experiment.** Every number in it comes from a scalar
disturbance-rejection simulation — PI controllers, resonator banks, a Kalman frontier. The paper
says so itself, twice, and unusually plainly:

- §III: "the disturbance is a stochastic signal with known statistics, not a model of cognition.
  The bridge to LLM-agent collectives … is a motivating analogy … **it is not part of the
  control-theoretic claims**."
- Appendix A.B: an LLM harness exists, runs against a mock backend, and "**the mock backend
  yields no scientific result**". The real-API path is explicitly "excluded from the paper's
  claims".

So it belongs in the reading list as a **vocabulary**, not as evidence about agents. Taken as
evidence it would be the exact error the rest of this list keeps finding: measuring one thing and
reporting it as another. Taken as vocabulary it is the cleanest statement I have seen of a
constraint three other papers here measured independently.

## The claim it is attacking

A recent preprint [9] argued that flat, homogeneous multi-agent systems have a
population-independent "causal floor" on error, removable **only** by hierarchical organisation.
This paper's move is a definitional one: "flat" conflates *flat in architecture* (no nested
loops) with *flat in memory* (no internal dynamical state). The impossibility holds for the
second and fails for the first — and refuting a **universal** claim needs exactly one
counterexample, which is all they claim to supply (Prop. 3 proof, verbatim: "We do not claim the
flat controller beats every hierarchy").

That is the right size of claim, and they keep it that size throughout. Contrast with most of
this reading list.

## The accounting

| Resource | Buys | Does **not** buy | Law |
|---|---|---|---|
| **Width** `N` (agents) | averaging of i.i.d. noise | structural / spectral content | `∝ 1/N` down to a floor; saturates at `N*` |
| **Per-agent memory** `d` | spectral coverage (internal model) | delay compensation | need `d ≥ 2 · #bands`; floor set by *uncovered* power |
| **Prediction over `τ`** | the predictable part of the disturbance | the innovation | floor = disturbance innovation over `τ+1` + delayed-sensing estimation error |
| **Adaptation** | replaces oracle knowledge | instant tracking | ≈ oracle − small gap; **loses under fast switching** |
| **Resonator damping** | width of robustness | depth at that width | notch waterbed: depth × bandwidth ≈ const |

Prop. 1 (width–structure non-exchange) is the load-bearing one: power in a frequency band whose
generator no agent models contributes an error bounded below by a constant **independent of N**.
More agents cannot buy coverage. Measured: on a two-band task at `N = 1000`, MSE 2.96 with one
band uncovered vs 0.25 with both covered — the uncovered band is flat in `N`.

Prop. 2 gives the delay floor as a conditional variance and it is verified **to <1 %** (max
0.89 %) against a semi-analytic Riccati floor across 15 `(a, τ)` combinations. That is the most
solid number in the paper and the least surprising: it is Åström 1970 restated in resource terms.

## The finding that survives translation — and the threshold that qualifies it

The width×memory heatmap has **L-shaped contours**: width slides you down a noise ramp *to a
fixed floor*; only memory lowers the floor. Floors at `N = 1000` on a 3-band task: `d=0` 4.49 ·
`d=1` 2.40 · `d=3` 2.05 · `d=5` 1.66 · `d=7` **0.44**.

But the honest part is Fig. 5, the strict equal-budget comparison (`N · d = B` on exact points):

| Budget `B` | deep (`d=7`) | wide (`d=1`) | verdict |
|---|---|---|---|
| 1 050 | 2.24 (`N=150`) | 2.37 (`N=1050`) | **a wash** |
| 3 150 | 0.80 | ≈2.3 | depth wins |
| 12 600 | 0.29 | ≈2.3 | depth wins decisively |

**Depth only dominates above a minimum SNR.** Below it, too few agents leave the measurement
noise unaveraged and the extra memory has nothing clean to model. The headline "memory beats
width" is conditional, and the paper prints the condition instead of burying it.

Two more places where memory is the wrong answer, both reported rather than tuned away:

- **Regime switching:** plain PI (0.59) beats the adaptive learned model (0.79), because each
  switch triggers a re-identification transient. The authors go further and call this
  "**fundamental to any learning scheme, not an artifact of our estimator**" — the transient is
  set by identification time, so a better regulator (RLS) would not remove it.
- **Nonlinear plant at small `N=10`:** PI (`d=1`, 16.4) is *worse* than plain P (`d=0`, 13.6) —
  integrative memory amplifies measurement noise when width is insufficient. The ordering only
  reappears at `N=300`.

## What is worth carrying over here

The mapping the paper proposes — width = parallel agents, memory = context and retrieval, delay =
reasoning latency — is a hypothesis it does not test. But three of its statements are things
**already measured on LLMs elsewhere in this reading list**, by different people, from a
different discipline, which is the only reason to trust the vocabulary at all:

1. **"No number of agents substitutes for a missing mode" is β.** Co-Failure Ceiling
   (`2606.27288`) measured the same wall on 67 models: every selection policy is capped at `1−β`,
   the rate at which *all* candidates fail together, and pairwise correlation provably cannot see
   it. Rule 1 here ("count the disturbance modes first") and the β certificate there are the same
   instruction in two languages: **measure what none of them can do before paying for more of
   them.** [[false 429]]
2. **"Add width only up to `N*`; beyond it agents are ballast."** The point where `1/N` reduction
   meets the structural floor is computable in advance from the noise variance and the target.
   The LLM version is the same arithmetic and is never run — a fan-out of 8 that all share a blind
   spot is 8 × the cost of the blind spot.
3. **"Scaling helps mainly when it adds diversity"** — which the paper cites [12] for and which
   Biased Consensus (`2608.02827`) *measured*: mixing temperatures and model families across
   agents cuts the shared bias. Replication averages noise; only diversity widens coverage.

And one rule that lands on our own files rather than on any agent design: **adaptation loses when
the world changes faster than re-identification.** A rule file, a routine, a handover note is an
internal model. When the situation turns over faster than we update it, a stale sharp model is
worse than a blunt robust default — which is the same failure as a `routines.md` line whose kill
condition fell weeks ago, and the same failure as "Sie waren nie im Haus" surviving into a later
draft. [[handover = live state]] [[retraction hits generator]]

## Craftsmanship note

Reproducibility here is the best of the 16 papers read so far: MIT-licensed code, Zenodo DOI
(`10.5281/zenodo.21295164`), Dockerfile, Conda env, CI targets (`make smoke`, `make check`),
deterministic regeneration from released seeds, **and no paid API needed for any core result**.
The limitations section names six concrete weaknesses (single tuned cascade baseline, coarse
tuning grid, narrowband-only adaptive controller, no inter-agent communication, i.i.d. sensing,
unconstrained actuators) and frames each as a testable extension. A paper that hands you the
list of ways it could be wrong is doing the thing the rest of this list mostly does not.
