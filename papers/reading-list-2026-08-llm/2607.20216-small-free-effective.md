# Small, free, and effective — the partner contributes 5 % of what the paper credits to the partner

The claim in the title is that orchestrated open-weight small models beat a single frontier LLM
on malware-report question answering. The measured margin is **35.30 % vs 34.77 %** on 609
questions — **0.53 percentage points, about 3.2 questions** — and the paper reports no
confidence interval, no significance test and no repeated runs anywhere (`grep` over the full
text: one occurrence of "significant", in the intro, in the plain-English sense; "seed" appears
once, as an argument for reproducibility, never as a reported protocol).

That margin is not the interesting part. The interesting part is in Appendix 0.E, where the
paper measures the control that would falsify its own framing, reports it in one sentence, and
does not connect it to the thesis.

## The finding: self-debate captures nearly all of the "collaboration" gain

The debate system pairs a general SLM with the cyber-specialised Foundation-Sec-8B for seven
rounds. The appendix also ran the diagonal — each model debating **a copy of itself**:

| Model | solo | **self-debate** | debate w/ Sec-8B expert | gain from having a *partner* |
|---|---|---|---|---|
| Ministral-8B | 10.84 % | **23.0 %** | 23.60 % | **+0.60 pp of +12.76 → 4.7 %** |
| Qwen3-0.6B | 11.05 % | **16.4 %** | 18.60 % | +2.20 pp of +7.55 → 29 % |

For Ministral-8B, **95 % of the debate gain is reproduced by talking to itself.** The
specialised expert — the whole premise of "orchestrating" heterogeneous models — buys
0.6 points. The paper's sentence for this is *"self-debates underperform except for the largest
models"*, and for the 0.6B case *"barely exceeding its single-model baseline of 11.05 %"* —
16.4 vs 11.05 is a 48 % relative gain, described as *barely*. The framing is relative to the
cross-model condition; measured against the baseline the paper itself is trying to beat, self-
debate is most of the effect.

This is exactly the placebo control missing from the self-repair literature in
[`2607.26117`](2607.26117-try-again.md) — **more rounds at more tokens**, versus *whose* rounds
they are. It is present here, and it is in an appendix.

**The one number that would settle it is not readable.** No self-debate figure is reported for
Qwen3-4B, the model that carries every headline in the paper. It should be the Table 7 diagonal,
but the HTML rendering substitutes `nicematrix-placeholder` for the entire table — the prose
quotes exactly three cells (Ministral 23.0, Qwen3-0.6B 16.4, Sec-8B×DeepHat 18.2). Whether the
decisive control was run and just not discussed cannot be determined from this rendering.

## Second contradiction: the symmetry is an assumption reported as a result

Table 7's caption: *"Only the upper triangle is shown due to the symmetry of the debate
setting."* Section 0.E: *"the matrix is symmetric: swapping which model acts as Agent A versus
Agent B produces identical accuracy, **indicating that debate outcomes are independent of role
assignment**."*

Symmetry cannot be both the reason the lower triangle was never run and the finding derived from
it. And *identical* accuracy on 609 stochastic questions under a role swap is not a plausible
measurement — it is the definition of a matrix that was filled in once and mirrored.

Role order in multi-agent debate is not free: the next paper in this list
([`2605.10698`](2605.10698-bystander.md), lead-anchor asymmetry) measures Δ𝒜 ≠ 0 under exactly
this swap and calls the non-commutativity of multi-agent topologies its result. One of the two
papers is measuring something the other assumed away.

## What actually does the work: the dumb tools, not the swarm

The component ablation (Table 3, Qwen3-4B + Sec-8B):

| Configuration | Easy | Hard | Overall |
|---|---|---|---|
| Full hybrid | 38.14 % | 27.27 % | **35.30 %** |
| − evidence collection (pure debate) | 25.50 % | 22.73 % | 24.13 % |
| − debate (pure agentic) | 26.50 % | 20.00 % | 25.11 % |
| − grounding constraint | 36.21 % | 26.14 % | 33.79 % |
| − verifier | 37.82 % | 26.52 % | **35.04 %** |

**The verifier — the one LLM-shaped quality gate — is worth 0.26 pp.** The evidence-collection
phase, which is `grep`, `jq`, a 150-keyword trigger list, a deterministic MITRE ATT&CK API
lookup and a 22.7M-parameter embedding filter at cosine τ > 0.65, is worth 11.17 pp. Figure 3
isolates it further: *tool access provides the largest performance boost for all four models*,
and the enrichment trigger is explicitly *"deterministic (keyword/pattern match), not LLM-driven,
to ensure reproducibility"*.

The paper belongs in section 3 of this reading list by its title and in **section 4** by its
result.

## Third: what "beats the frontier model" survives an evidence-matched comparison

Table 4 is the paper's own fairness check — run the frontier models through the *same* pipeline:

| | Easy | Hard | Overall |
|---|---|---|---|
| Gemini 3 Pro, ungrounded | 38.00 % | 22.73 % | 34.77 % |
| **Gemini 3 Pro, grounded** | 41.24 % | 29.55 % | **38.22 %** |
| Claude Opus 4.5, grounded | 39.29 % | 28.68 % | 36.85 % |
| Qwen3-4B + Sec-8B (the headline) | 38.14 % | 27.27 % | 35.30 % |

Given the same evidence, **both frontier models beat the SLM hybrid**, and the abstract says so
("grounded Gemini remained the strongest configuration at 38.22 %"). The title's comparison is
against a baseline that was denied the tooling. The real result is the one the discussion
eventually states: *evidence-grounded orchestration is a general framework that helps every
model size* — the SLM part is a deployment story (local, $0 API), not a capability story.

## The Hard tier is 22 questions

`n=22`. **One question is 4.55 percentage points.** In Table 1, ten of the twenty baseline models
score exactly 4.55 % on Hard — one question — and four score 0.00 %. Every Hard-tier claim in the
paper is therefore a difference of one or two questions:

- hybrid 27.27 % (6/22) vs best ungrounded frontier 22.73 % (5/22) = **one question**
- "debate lifts hard-tier accuracy from 4.55 % baseline to 22.73 %" = **one question → five**

(Several frontier Hard values are *not* integer multiples of 1/22 — GPT-5.2 20.45 % = 4.5/22,
Claude 21.59 % = 4.75/22 — which would fit averaging over repeated API runs while local models
ran once. The paper does not state a run protocol either way.)

Weighting compounds this: Easy is 451 of 609 questions (74 %), so the overall column is
essentially the Easy column. The paper flags this itself.

## Hyperparameters chosen on the reported benchmark

Four, with no held-out split mentioned for any: the seven-round debate depth (*"selected based on
the optimal trade-off"* visible in Figure 4), the τ = 0.65 evidence threshold (*"determined
empirically"*), the 150-keyword enrichment vocabulary (*"a size determined empirically"*), and
the 4× parameter-ratio partner heuristic. Only the last is labelled as benchmark-specific and
not validated. This is the same class of hazard as choosing a critic threshold on the set you
then report.

## The honest cost picture

| System | latency | API cost / 609 Qs | overall |
|---|---|---|---|
| Gemini 3 Pro (API) | 3.2 s/q | $7.54 | 34.77 % |
| Claude Opus 4.5 (API) | 4.8 s/q | $96.22 | 33.15 % |
| Qwen3-4B (local, solo) | 1.8 s/q | $0.00 | 16.58 % |
| **Hybrid (local, RTX 4090)** | **105.6 s/q** | $0.00 | 35.30 % |

Arithmetic on their Table 5: the full run is **17.9 hours** of GPU wall-clock against Gemini's
**32 minutes**, to save **$7.54**. The paper states plainly that the $0.00 excludes electricity,
hardware, hosting and support — at ~400 W that run alone is ~7 kWh, so the *cash* saving against
Gemini is a couple of euros before the card is paid for. "Free" here means *no invoice*, not
*no cost*, and the 33× latency is the price of the thing that made it work.

## Also worth carrying

- **Specialisation beats size in the expert seat.** Foundation-Sec-8B as consultant beat a
  general LLM consistently, and scaling the expert 8B → 70B gave *minimal* additional gain.
  Solo, the 70B cyber model scores 22.54 % vs the 8B's 19.96 % — the extra 62B parameters buy
  2.6 points solo and ~nothing as a partner.
- **Debate rounds have opposite signs by difficulty.** Hard-tier accuracy rises and plateaus at
  7–10 rounds; Easy-tier accuracy *peaks* there and declines to round 15, because the debate
  introduces tangential material that pulls correct answers away. Grounding is what stops it.
- **Parameter count does not predict capability**: Qwen3-4B (16.58 %) beat every 7–8B model
  tested, including Qwen2.5-Coder-7B (11.66 %) and Llama-3.1-8B (12.15 %).
- **The contamination audit is a good template.** Temporal cutoff check, 13-gram overlap against
  a reference corpus (0.0 %), and TS-Guessing: mask the correct option, ask the model to fill it
  → 13.8 % vs a 0.63 % random baseline for perfect multi-label match, and 35.30 % with evidence.
  They report the uncomfortable middle number rather than only the clean one.
- Absolute ceiling: 35.30 % exact match. The paper's own discussion says this is *"insufficient
  for autonomous malware-analysis decisions"* and positions the system as analyst assistance.

**→ hier:** four transfers.

1. **Run the self-debate diagonal before believing any multi-agent gain.** The cheapest control
   in the whole reading list: same architecture, same round count, same token budget, **one
   model in both seats**. Ministral-8B says 95 % of the "collaboration" was available without a
   collaborator. Any actor/critic or debate arrangement here that has not been measured against
   *itself twice* is reporting the round count, not the ensemble. Same instrument as
   [[2607.26117 blind resampling]] and the Pivotal Vote permutation control.
2. **This is a section-4 paper wearing a section-3 title, and that is the pattern to expect.**
   `grep`, `jq`, a keyword list and a deterministic API lookup carry 11.17 pp; the LLM verifier
   carries 0.26 pp. When an orchestration result looks good, ablate the deterministic parts
   first — they are usually the load-bearing ones. [[unrunnable check]] [[absence test]]
3. **Never compare a grounded system against an ungrounded baseline.** The paper's honest
   Table 4 flips its own headline: with the same evidence pipeline, Gemini wins by 2.9 points.
   The local mirror: when I claim a scaffold beat a plain call, the plain call must get the same
   context, tools and evidence — otherwise I measured the retrieval, not the scaffold.
4. **Check the denominator before quoting a tier.** `n=22` makes one question worth 4.55 pp,
   and ten of twenty models sit at exactly one question. The same arithmetic applies to my own
   small-sample claims — FinGrab's 7 reviews, a 12-sample case study, a three-question A/B.
