### Using the models well
- **2026-09-14** · [Building a Software Factory that actually works (Full Course)](2026-09-14-software-factory-isolate-build-prove-ship-ras-mic.md) — Ras Mic shares his screen and walks the whole system: **isolate → build → prove → ship**, carried by *"about five or six files"*. The definition is the first payload — *"a software factory is completely harness and model agnostic"*, *"not a product"*, *"just a bunch of markdown files"*; and the `agents.md` rule that follows from it: put in only what is **not native to the agent** (*"most people's agent.md file is useless"*). **Isolate** = a fresh `git worktree` off origin main per feature, because *"almost always it's because people have their agents working on different features on the same branch"*; Greg renames it **team** on air and Ras Mic accepts. **Build** = a `code structure` skill writing service-layer code, since *"just because it works doesn't mean it's written well"*. **Prove is the step almost nobody has** — *"agents can't pinky promise"* — the agent records a before state and an after state (video, screenshots, or numbers: 817 ms → 61 ms on a performance PR) **into the PR body**, and loops back to build by itself when the after shot fails, *"I didn't have to tell it"*. **Ship** = Greptile scores the PR; below five out of five the agent re-enters build → prove → ship unprompted, and only at 5/5 does the human merge — while 15 features run in parallel. Greg's analogy is better than the names: own station · assembly line · quality control · out the door. **Measured against Otto: isolate and build already exist** (agent-tasks and Fabrik both run in worktrees), **prove does not — 0 of the last 120 merged PRs in `assistant` + `solytics` carry a single image**, and `/quality-gate` reports to Telegram, not to the PR, so **0 of the last 30 merged `assistant` PRs carry a review of any kind** and no score can loop back. Not to copy: *"I'm not reading all my code nowadays"* — he earned that with the two gates first
